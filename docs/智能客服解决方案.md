# 智能客服解决方案（文字版）

> 基于对话平台（DPaaS）的企业级智能客服方案，覆盖在线客服、人工辅助、热线语音与终端语音控制等场景。  
> 适用于快速搭建可运营、可配置、可转人工的对话机器人。

---

## 一、方案概述

本方案以「知识驱动 + 多引擎协同 + SaaS 运营控制台」为核心，为企业提供可落地的智能对话能力：

| 层次             | 定位           | 主要内容                                                        |
| ---------------- | -------------- | --------------------------------------------------------------- |
| **DPaaS 对话层** | 原子问答能力   | FAQ、闲聊、对话工厂、图谱问答、机器阅读、表格问答、数据报表问答 |
| **基础算法层**   | 通用 NLP 能力  | 分词、地址识别、文本摘要、情绪检测、机器阅读、机器翻译等        |
| **知识系统层**   | 知识全生命周期 | 知识挖掘 → 知识管理 → 知识表示 → 知识闭环                       |

**建设目标：**

1. 自动识别并回复用户问题，降低人工接待成本
2. 复杂/敏感场景可平滑转人工
3. 知识可配置、可发布、可运营、可迭代

---

## 二、适用业务场景

### 2.1 在线智能客服

- **部署位置：** App、Web、微信等渠道
- **能力：** 自动识别用户意图并回复；配套对话能力配置、知识库维护、数据分析
- **价值：** 提升自助解决率，降低人工成本

### 2.2 在线智能辅助

- **部署位置：** 人工客服工作台（自研或采购）
- **能力：** 坐席接待时，系统推荐机器人答案/检索结果，辅助更快更好回复
- **要求：** 对接 API + 维护知识库


## 四、智能对话能力

| 能力               | 说明                                       | 要点                                               |
| ------------------ | ------------------------------------------ | -------------------------------------------------- |
| **FAQ 问答**       | 基于企业预置问答对，识别相似意图并返回答案 | 支持自定义 FAQ 库；可订阅官方知识包                |

| **多语言问答**     | 将 FAQ / 闲聊 / 任务式多轮能力扩展至英语等 | 按业务需要开通                                     |

## 六、快速创建对话机器人（实施路径）

### 6.1 整体步骤

```
创建/选择机器人
    → 绑定 FAQ 类目（单轮问答）
    → 配置对话流（多轮任务）
    → 绑定表格（结构化数据问答，可选）
    → 配置闲聊语料包
    → 配置问答策略（欢迎语/敏感词/无答案/阈值）
    → 配置转人工策略
    → 测试验证
    → 发布（测试环境 → 正式环境）
```

### 6.2 入口说明

路径示例：

- **机器人中心 → 机器人管理 → 选择机器人 → 管理**
- 配置页常见 Tab：绑定知识 / 转人工策略 / 问答策略配置 / 会话接口 / 全局知识

环境切换：**测试环境** / **正式环境**（建议先在测试环境完成配置与验证）。

## 七、知识配置详解

### 7.1 FAQ 类目绑定（单轮问答）

- **用途：** 绑定「一问一答」知识，支撑简单单轮问答
- **路径：** 机器人管理 → 选择机器人 → **FAQ 类目绑定**
- **操作：** 点击「添加类目」，将 FAQ 类目绑定到机器人并保存

#### 在 FAQ 库创建知识

1. 进入 **知识中心 → FAQ 管理**
2. 确认处于 **测试环境**
3. 新增方式：
   - **在线创建 FAQ**：填写标准问、相似问、关联问题、生效时间等
   - **批量导入**：下载 Excel 模板，支持「覆盖」或「合并」
4. 列表可查看生效状态、发布状态；就绪后执行发布
5. 创建/整理类目后，回到机器人侧完成 **类目绑定**

### 7.2 对话管理 / 对话工厂（多轮问答）

- **用途：** 配置任务式、流程式多轮对话
- **路径：** 机器人配置页 → **对话管理** → 「新建对话」或「去对话工厂」
- **说明：** 在对话工厂画布上设计对话路径、节点与跳转逻辑

### 7.3 表格绑定

- **用途：** 基于结构化表格做查询与推理问答
- **路径：** 机器人配置 → **绑定表格**
- **能力：** 复杂推理、跨表查询、多轮交互

### 7.4 闲聊语料

- **用途：** 为机器人配置闲聊能力，处理非任务型寒暄
- **路径：** 机器人配置 → **闲聊语料库**
- **说明：** 可使用预置语料包，也可自定义维护

## 八、问答策略配置

机器人问答策略支持配置欢迎语、敏感词话术、无答案默认话术、澄清条数及整体问答逻辑。

### 8.1 话术配置

| 功能               | 说明                     | 示例                                                                       |
| ------------------ | ------------------------ | -------------------------------------------------------------------------- |
| **欢迎语话术**     | 用户进入对话时的首条消息 | 「智能对话机器人为您服务，请问有什么可以帮您？」                           |
| **敏感词话术**     | 命中敏感词时的默认回复   | 「您说的这个问题我不能回答您，您可以尝试询问其他问题」                     |
| **无答案默认话术** | 找不到答案时的兜底提示   | 「我还没有学会这个问题，已经记录会尽快学习为您解答，请尝试询问我其他问题」 |

> 欢迎语卡片、快捷入口矩阵、富媒体卡片等高级 UI，通常在 **渠道管理** 中配置。

### 8.2 问答策略模式

| 模式                               | 行为                                                                                                   |
| ---------------------------------- | ------------------------------------------------------------------------------------------------------ |
| **允许澄清和直出**（先直出再推荐） | 高于直出阈值 → 直接回复；介于澄清阈值与直出阈值之间 → 以推荐/澄清形式展示；低于澄清阈值 → 不回复该引擎 |
| **仅允许直出**（只直出）           | 仅高于直出阈值才回复；关闭推荐/澄清能力                                                                |

**澄清条数（1–10）：** 触发澄清时，返回最相似的 Top N 条知识（如默认 3 条）。

### 8.3 阈值配置（算法置信度）

阈值影响引擎是否回复、是否澄清、是否直出。示例如下（可按业务调优）：

#### FAQ 问答

| 区间                                    | 行为         |
| --------------------------------------- | ------------ |
| 分数 &lt; 知识澄清阈值（如 0.0100）     | 引擎不回复   |
| 澄清阈值 ≤ 分数 ≤ 直出阈值（如 0.9000） | 引擎澄清     |
| 分数 &gt; 直出阈值                      | 引擎直接回复 |

#### 对话工厂

| 区间                                    | 行为         |
| --------------------------------------- | ------------ |
| 分数 &lt; 匹配澄清阈值（如 0.4000）     | 引擎不回复   |
| 澄清阈值 ≤ 分数 ≤ 直出阈值（如 0.7500） | 引擎澄清     |
| 分数 &gt; 直出阈值                      | 引擎直接回复 |

#### 文档问答

| 区间                                | 行为                           |
| ----------------------------------- | ------------------------------ |
| 分数 &lt; 文档识别阈值（如 0.4800） | 引擎不回复                     |
| 分数 ≥ 阈值                         | 引擎直接回复（通常无澄清区间） |

#### 闲聊

| 区间                            | 行为                           |
| ------------------------------- | ------------------------------ |
| 分数 &lt; 直出阈值（如 0.9000） | 引擎不回复                     |
| 分数 ≥ 直出阈值                 | 引擎直接回复（通常无澄清区间） |

**调优建议：**

- FAQ 直出阈值偏高 → 答得更准，但可能更多「无答案」或澄清
- 澄清阈值过低 → 容易乱推荐；过高 → 澄清机会少
- 闲聊阈值建议偏高，避免抢答业务问题

## 九、意图管理（多轮对话）

### 9.1 功能入口

1. 登录智能对话机器人平台
2. **机器人中心 → 对话工厂**
3. 选择目标机器人
4. 进入 **意图管理** Tab

同区常见模块：对话单元草稿、实体管理、变量管理、全局欢迎语卡片模板等。

### 9.2 新增意图

1. 点击 **新增意图**
2. 填写：
   - **意图名称**（可读名称）
   - **意图 code**（唯一标识，创建后不可修改）
3. 补充问法模板、别名等后保存、发布

### 9.3 问法模板（LGF 语法）

LGF 用于描述与匹配用户问法，类似面向 NLP 的简化正则：

| 语法     | 含义             | 示例                         | 说明                                               |
| -------- | ---------------- | ---------------------------- | -------------------------------------------------- |
| `${}`    | 引用实体参数     | `${城市}`                    | 匹配实体管理中的城市等实体                         |
| `[]`     | 可选符           | `[请\|麻烦]帮我打水`         | 「帮我打水」「请帮我打水」「麻烦帮我打水」均可匹配 |
| `()`     | 必选符           | `附近的 (餐馆\|饭店)`        | 必须命中「餐馆」或「饭店」之一                     |
| `\|`     | 或               | `小明的 (电话\|联系方式)`    | 二选一                                             |
| `.{m,n}` | 任意字符长度区间 | `.{0,3}${日期}${城市}的天气` | 前缀 0–3 个任意字符                                |

## 十、转人工设置

### 10.1 功能入口

1. **机器人管理 → 选择机器人 → 管理**
2. 打开 **转人工策略** Tab

### 10.2 触发条件（均可开关）

| 条件               | 说明                                             |
| ------------------ | ------------------------------------------------ |
| **机器人无回复**   | 连续 N 次无法回答时转人工                        |
| **机器人重复回答** | 连续 N 次给出相同答案时转人工                    |
| **用户重复提问**   | 用户连续 N 次问相同问题/触发相同意图时转人工     |
| **关键词转人工**   | 用户输入命中自定义关键词（支持 LGF）时转人工     |
| **情绪转人工**     | 识别到愤怒、辱骂等负面情绪时转人工，降低投诉风险 |

### 10.3 转人工回复话术

可自定义转接前对用户的提示，例如：「正在为您转接人工客服，请稍候…」

### 10.4 参数设置

| 参数           | 说明                           |
| -------------- | ------------------------------ |
| **技能组**     | 指定转接到哪个人工技能组       |
| **自定义参数** | 转接时一并传给坐席侧的业务参数 |

### 10.5 客服工作台响应

#### 方式 A：对接云厂商自有客服产品

- 填写技能组 ID 即可自动同步消息与历史
- 一般无需二次开发（渠道部署侧做少量配置）

#### 方式 B：对接第三方客服工作台

1. 在机器人控制台配置转人工行为（技能组、自定义参数等）
2. 触发时，机器人通过 **ChatAPI** 将指令下发，关键字段通常在 **Output-Commands**
3. 企业服务端解析 Commands，自行执行转接到自有坐席台的逻辑

## 十一、测试与发布

### 11.1 测试

- 配置完成后，使用控制台右侧悬浮 **「测试」** 按钮打开全屏测试窗
- 建议覆盖用例：
  - FAQ 命中 / 相似问
  - 多轮对话主路径与异常路径
  - 闲聊是否抢答业务问题
  - 敏感词、无答案兜底
  - 澄清推荐条数与阈值边界
  - 转人工各触发条件

### 11.2 发布

1. 测试环境验证通过
2. 通过 **发布机器人** 将变更发布
3. 需要时经 **发布中心** 将测试数据同步至正式环境
4. 可通过 **发布记录** 回溯历史版本

## 十四、总结

本方案形成完整闭环：

**知识建设（FAQ / 多轮 / 表格 / 闲聊）→ 策略与阈值调优 → 转人工兜底 → 渠道发布 → 数据运营与知识闭环**

企业可按「先 FAQ 自助、再多轮任务、最后语音/辅助坐席」的路径分阶段上线，在控制成本的同时持续提升解决率与体验。
